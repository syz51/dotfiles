# Frontend patterns to avoid

Visual patterns the user has declined as defaults. When choosing a direction for a new interface or substantial redesign, do not use them unless the brief, a reference, or the existing project calls for them. Keep project-specific exclusions in that project's instructions.

Add an entry when the user rejects a pattern as an unwanted default, not for feedback on a single design. Describe each pattern concretely enough to recognize, one per line.
