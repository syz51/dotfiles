# Continuing a branch held by another worktree

This rule is part of the global instructions (`~/.claude/CLAUDE.md`, Workflow section) and has the same force. Read it before continuing a branch that another worktree has checked out.

- To continue a branch that another worktree has checked out, which git refuses to check out twice, work on a local branch started from `origin/<branch>` and push to `<branch>`; brief a child that continues one the same way.
