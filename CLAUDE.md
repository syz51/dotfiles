# Dotfiles

- After testing, review and clean up temporary test files, including session transcripts and folders the test created.
- Keep the test suite in step with every change: add or update tests for the behavior you touch, and when removing or replacing behavior, rewrite its tests to pin the new behavior instead of deleting them. After each change, run the suites in SETUP.md's Verification section, including the opt-in live suites when Claude Code behavior is affected.
